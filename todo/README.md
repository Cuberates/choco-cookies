Inspiration
Bowlers across the US and Canada juggle fragmented platforms—using one site for local leagues and separate databases for bowling ball specs. Bowl Index solves this decentralization by bringing everything into one unified hub.

What it does
Bowl Index is a centralized platform where bowlers can log equipment arsenals, track technical specs (RG, differential, surface), and monitor league scores in a single dashboard.

How we built it
Frontend: A responsive UI designed for quick access at home or at the lanes.

Backend: A robust database structured to link complex equipment specifications with performance data.

Challenges we ran into
Consolidating disparate data types—from numerical gear specs to scoring logs—into a clean, cohesive schema.

Designing an interface fast and intuitive enough for active league bowlers.

Accomplishments that we're proud of
Building the foundational framework for a centralized ecosystem combining equipment and performance tracking.

What we learned
Frictionless data entry is vital for adoption in a community used to traditional tracking methods.

What's next for Bowl Index
Advanced Analytics: Smart recommendations based on historical performance and lane conditions.

Community Features: Arsenal sharing and direct pro shop integration.
